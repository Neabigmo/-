Stage27U retry4A: auditable single-witness dual pruning overlay
Date: 2026-09-03

Base branch expected:
  stage27u-retry3-gradient-audit-overlay-2026-09-03

Purpose:
  Diagnose and remove NNQP success=False failures that occur only in strongly
  positive regions, without changing the NNQP solver or weakening any final audit.

Mathematical rule:
  For f(alpha)=alpha^T C alpha+2 c^T alpha, alpha>=0, choose alpha=t e_j.
  If c_j<0, t=-c_j/C_jj and
      m_tail^2 >= c_j^2/(C_jj eps^2).
  This is a feasible-dual lower bound and needs no KKT convergence.

Retry4 interception rule:
  - only intercept FloatingPointError messages beginning with "NNQP invalid";
  - identify promising one-witness coordinates from the existing normalized QP;
  - independently replay up to 4 witnesses with mpmath at >=260 dps;
  - certify prune only if E + one_witness_lb - A >= +25;
  - otherwise re-raise the original NNQP failure unchanged.

Search behavior:
  A certified prune aborts only the affected local search step/start. If the
  original start is scientifically valid, local_search falls back to it.
  A start that is itself pointwise-pruned is excluded from finalists.
  No artificial prune point can become a scientific candidate.

Audit:
  stage27u_retry4_dual_prune.csv records every unique pointwise prune.
  audit_retry4.py independently replays each row at >=300 dps, then runs the
  complete retry3 audit, which itself runs the retry2 artifact-replay audit.

Unchanged:
  Fock completion, OU coherence, Mehler Gram, fixed ridge, NNQP solver, continuum
  exchange, final candidate validation, N=32/48/64/80 coverage, gradient threshold.

This is numerical workflow repair only. It is not a theorem certificate.
