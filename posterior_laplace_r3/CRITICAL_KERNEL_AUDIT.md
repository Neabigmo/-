# Critical-kernel audit

The natural Gaussian-equality lower bound was tested before any search:
`K_{v,r} f >= K_Gaussian`.  For the genuine heat-smoothed prior
`mu=(delta_-1+delta_+1)/2`, at `v=r=1,y=0`, exact expansion gives

`K = 1/2+(3/2)e^(-2/3) < 3/2 = K_Gaussian`.

Thus the proposed one-sided inequality is rigorously false and the mechanism
is stopped.  This is an exact counterexample to that candidate inequality,
not to the original Gaussian characterization.
