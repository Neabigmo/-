# Moment relaxation countermodel

The finite conditional-moment constraints through order four admit the exact
abstract model in `certify_moment_countermodel.py`: `V` has three explicit
values and the conditional law is Rademacher at `+/-sqrt(V)`.

It has `E[V]=1`, `E[V^2]=3/2`, `E[V^3]=27/8`, `E[V^4]=81/8`, and reproduces
`E[Q^k]=2^k k!` for `k=1,...,4`, while `Var(V)=1/2` and `P(Q=0)=1/3`.

This is only a formal hierarchical moment model.  It is not a posterior
family generated by one common prior and is not an actual counterexample.
