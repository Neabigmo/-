# Common symmetric zero reduction

R12 proved

```text
D_R(z)+C_R(z)=R(-z/2)^2,
D_R(z)-C_R(z)=R(z/2)^2.
```

Therefore a common nonzero `D_R/C_R` root is equivalent to a symmetric zero
pair

```text
R(zeta/2)=R(-zeta/2)=0.
```

R13 does not assume that probability rules out complex symmetric zero pairs;
that is a separate future question and no zero search is started here.
