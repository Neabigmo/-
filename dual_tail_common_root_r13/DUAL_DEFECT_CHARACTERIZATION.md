# Dual defect characterization

Let `L_e=L_R^ee:X_rho -> X_rho` and `B_o=L_R^eo:Y_rho -> X_rho`.  Since
`L_e` is Fredholm, the finite-dimensional map

```text
Delta_rho: Y_rho --B_o--> X_rho --> coker(L_e)
```

is not surjective exactly when there is a nonzero bounded dual functional
`phi` that annihilates both `L_e` and `B_o`, equivalently

```text
L_e^* phi=0,   B_o^* phi=0.
```

This is a functional-analytic characterization, not a replacement of the
exact cokernel by principal evaluation jets.  The latter replacement is
invalid after arbitrary compact perturbations.
