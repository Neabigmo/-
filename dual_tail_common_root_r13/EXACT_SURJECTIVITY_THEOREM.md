# Conditional exact surjectivity theorem

The precise conditional statement is:

```text
If the normalized dual-tail locality estimate holds for K_e and K_o, and
Delta_rho is not surjective, then Dtilde_R and Ctilde_R have a common interior
zero (subject to the boundary-zero-free radius choice).
```

The proof is the chain

```text
dual annihilator -> normalized tail limit -> two constant-coefficient
recurrences -> shift spectral mapping -> common D/C root.
```

R13 does not promote this conditional statement to a theorem because R11's
compactness proof does not provide the required relative estimate.
