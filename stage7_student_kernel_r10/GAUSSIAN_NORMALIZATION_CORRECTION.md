# Gaussian normalization correction

With the Fock convention `R(z)=E exp(zX-z^2/2)`, a standard Gaussian gives
`E exp(zX)=exp(z^2/2)`, hence `R(z)=1`.  Consequently
`D_R(z)=[R(z/2)^2+R(-z/2)^2]/2=1`.

The previous `exp(-z^2/4)` example used a different profile and must not be
used as the Gaussian replay for this project.
