# Wiener cubic compactness

For ordinary coefficients, a bound `|A_{ijk}/A_{n00}|<=C sqrt(n+1)` combines
with `eta=r/R<1` to give `C sup_{n>=2N}sqrt(n+1)eta^n -> 0` for two-high
terms, and the same expression with `n>=3N` for three-high terms. This is a
radius-loss compact-tail argument on `W_R -> W_r`, not finite-dimensional
compactness.
