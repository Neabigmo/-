# Low-order cone countermodel

At `d=1`, use a two-state abstract mixture. State A has weight `8/9` and a symmetric two-point centered law with variance `3/4`; state B has weight `1/9` and variance `3`. For a symmetric two-point law, `mu3=0`, `mu4=V^2`, and `mu6=V^3`.

The mixture has `E[V]=1`, `E[mu4+3V^2]=6`, and `E[mu6+12Vmu4-7mu3^2+3V^3]=54`, while `V` is nonconstant. This falsifies pointwise low-order posterior-moment closure only; it is not an indexed Fock/probability counterexample.
