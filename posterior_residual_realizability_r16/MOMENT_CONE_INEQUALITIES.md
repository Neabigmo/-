# Posterior moment cone

For a centered variable with variance `V>0`, Pearson's square gives `mu3^2 <= V*(mu4-V^2)`.

Projection of `Y^3` onto `span{1,Y}` gives `mu6 >= mu3^2 + mu4^2/V`.

Consequently, `mu6+12Vmu4-7mu3^2+3V^3 >= (mu4+3V^2)^2/V`.

This is an inequality, not an equality. The case `V=0` is handled separately by degeneracy.
