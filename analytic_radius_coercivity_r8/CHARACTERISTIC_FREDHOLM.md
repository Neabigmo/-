# Characteristic Fredholm defects

In the analytic-function realization of the candidate multiplication operator
`T_D:f -> D f`, let `zeta` be a zero of `D` of multiplicity `m`.  If
`|zeta|<r`, the evaluation/derivative functionals

`Lambda_{zeta,j}(g) = g^(j)(zeta)`, `0 <= j < m`,

are continuous on `H_r`.  The range of multiplication by `D` is contained in
their common kernel, and for a genuine one-variable multiplier these are the
exact `m` independent cokernel conditions; the kernel is zero unless `D` is
identically zero.  If `|zeta| >= r`, these functionals are not automatically
continuous on the target space, so the defect count cannot be asserted in
that space without changing the radius.

For R8 the resulting equations are recorded as

`Lambda_{zeta,j}( nonlinear/high-high remainder + finite-n correction ) = 0`.

They are named `CHARACTERISTIC SOLVABILITY DEFECTS`.  No positivity argument
has been found here that forces these defects to vanish.  The audit therefore
records `POSITIVITY_ACTION_ON_FREDHOLM_DEFECT_UNRESOLVED`.
