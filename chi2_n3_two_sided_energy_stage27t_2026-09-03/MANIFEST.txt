REQUIRED EXTERNAL INPUTS (NOT PART OF THE STAGE27T SOURCE PACKAGE)
-----------------------------------------------------------------
1. Stage27R robust PSD-repair result tree supplied via --stage27r-dir.
   The locator searches recursively. The following binary NPZ artifacts must
   be present somewhere under that directory:

   q0p05_N80_ridge1em11.npz
   q0p05_N96_ridge1em11.npz
   q0p1_N64_ridge1em11.npz
   q0p08_N80_ridge1em11.npz
   q0p064_N100_ridge1em11.npz
   q0p05_N128_ridge1em11.npz
   q0p04_N160_ridge1em11.npz
   q0p1_N80_ridge1em11.npz

   Each NPZ is expected to contain at least:
     witnesses, alpha (or usable fallback), slack (or usable fallback), u

2. Stage27S continuum result tree supplied via --stage27s-dir.
   The locator searches recursively. It must contain:

   stage27s_continuum.csv

   That CSV must contain rows/labels:
     A, B, C1, C2, C3, C4, C5, D
   and the fields needed by run_stage27t.py, in particular m2 and status.

3. Python environment:
   Install requirements.txt before running selftest or production.

IMPORTANT
---------
This Git repository transfer contains the full Stage27T TEXT SOURCE PACKAGE,
but it is NOT self-contained with respect to the external Stage27R NPZ result
artifacts or the Stage27S result CSV. Do not run Stage27T unless those inputs
are available and passed explicitly as described in RUN_ME.md.

Stage28 and OU-coherent multi-q are intentionally not included or launched.
