# Odd-to-even principal symbol

For fixed low pair degree `m=j+k`, endpoint localization gives

```text
A_(n-m,j,k)/A_n00 -> (-1/2)^m.
```

The even pair degrees produce

```text
D_R(z)=(R(z/2)^2+R(-z/2)^2)/2,
```

while the odd pair degrees produce the odd symbol

```text
C_R(z)=(R(-z/2)^2-R(z/2)^2)/2=z*Ctilde_R(z^2).
```

The two identities

```text
D_R+C_R=R(-z/2)^2,
D_R-C_R=R(z/2)^2
```

are exact.  Hence for `zeta != 0`, `D_R(zeta)=C_R(zeta)=0` if and only if
`R(zeta/2)=R(-zeta/2)=0`.  In the `w=z^2` coordinate this is the common
zero criterion for `Dtilde_R` and `Ctilde_R`.
