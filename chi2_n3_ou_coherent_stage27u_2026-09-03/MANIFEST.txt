REQUIRED EXTERNAL BINARY INPUTS — STAGE27R
------------------------------------------
Pass the Stage27R result tree with --stage27r-dir / STAGE27R_DIR.
The locator searches recursively and requires exactly these robust high-q witness artifacts:

q0p1_N64_ridge1em11.npz
q0p1_N80_ridge1em11.npz

Stage27U uses their saved `witnesses` arrays. No Stage27R primal artifact is required.

REQUIRED EXTERNAL TEXT INPUT — STAGE27S
---------------------------------------
Pass the Stage27S result tree with --stage27s-dir / STAGE27S_DIR.
Required:

stage27s_continuum.csv

It must contain labels C1 and D with eta_lambda / eta_s (when available these are added to the
high-q seed witness pool).

OPTIONAL BUT RECOMMENDED STAGE27S INPUT
---------------------------------------
stage27s_exchange_history.csv

If present, the saved C1/D continuum worst points are added to the witness seed pool.
The package still runs if this file is absent.

OPTIONAL PRIOR-CANDIDATE INPUTS
-------------------------------
Stage15 and Stage16 result roots may be supplied with --stage15-dir / --stage16-dir.
These are NOT required for execution. `candidate_loader.py` is deliberately conservative:
only explicit normalized-u candidates with recoverable q metadata are accepted. Ambiguous
old arrays are skipped rather than reinterpreted.
